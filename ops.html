Ops @ Deployment, Monitoring, Security

Deployment (CI/CD)

Flux & GitOps: Bootstrap-Repo + mehrere einzelne Repositories auf GitHub. Automatisierte Deployments via Flux. Secrets: Nutzung von SealedSecrets / Vault (je nach Anwendung). Branch‑Policies und Reviews für kritische Änderungen.

Kubernetes (Kurz)

  • StorageClasses: ZFS hostpath + Synology iSCSI
  • Network: Cilium + Cilium LB, Multus für zusätzliche Interfaces
  • kubevirt für VM‑Workloads
  • Cloudflared Container für Tunnels im Cluster

Monitoring / Observation

Grafana‑Dashboards für Host- und K8s‑Metriken. Alerts sind konfiguriert; Logs lokal bzw. im vorgesehenen Stack (Loki/ELK optional).

Security

Keycloak für Authentifizierung (OIDC). Firewall segmentiert VLANs; LAGG zwischen FW und Switch. Keine sensiblen Konfigurationen öffentlich.
